Desktop Publishing

Every flyer, programme, newsletter and certificate somebody reads was designed by somebody. In twelve Saturdays you learn page set-up, type and hierarchy, grids, colour, images and print preparation, and you finish with a four-page magazine printed for your centre. Free tools only: Canva, Google Docs, LibreOffice and Scribus.

How each Saturday works

  1. Recall — the session opens with last week's questions, before anything new.
  2. Understand — one idea, a picture of it and a worked example.
  3. Do — practise it on something real, with support and stretch.
  4. Show — every week ends in work that is assessed: a practical, an outside exercise, a written answer.

1What desktop publishing is — and the tools for it
Desktop publishing is designing pages to be read — on paper or on screen. Free tools do it well.
  • Say what desktop publishing is, with five examples
  • Tell print design from screen design
  • Choose a free tool for a job

2Setting up the page: size, orientation, margins
Before any design, set up the page: the paper size, which way up, and the margins that keep things safe.
  • Name common paper sizes (A4, A5, A3)
  • Choose portrait or landscape
  • Set margins and know why they matter
Slides
3Type I: choosing and using fonts
Most of a page is words. The right font, size and spacing make them easy to read.
  • Tell serif from sans-serif fonts
  • Set body text at a readable size and line length
  • Use at most two fonts on a page
Slides
4Type II: hierarchy — what to read first
Size, weight and colour tell the reader what matters most. A clear hierarchy gets the message across in seconds.
  • Build a five-level hierarchy
  • Use size, weight and colour — not many fonts
  • Test a design with the three-second glance
Slides
5Layout: the grid and four principles
Professional pages line up. A grid and four principles — contrast, repetition, alignment, proximity — make any page look designed.
  • Use a column grid to place things
  • Apply contrast, repetition, alignment and proximity
  • Critique a layout with the four principles
Slides
6Colour: schemes, contrast, and screen vs print
Use few colours, make text readable, and remember that screens and printers make colour differently.
  • Build a colour scheme from the colour wheel
  • Check text contrast (aim for 4.5:1)
  • Explain RGB versus CMYK
Slides
7Images: resolution, cropping and rights
A picture must be sharp enough to print, cropped with purpose, and yours to use.
  • Explain 72 vs 300 ppi
  • Crop an image to strengthen it
  • Use images legally and credit them
Slides
8Project: an event flyer from brief to print
Put it together: a one-page flyer for a real Club event, designed from a brief and checked before printing.
  • Work from a client brief
  • Apply hierarchy, grid, colour and images together
  • Check a design with a proof checklist
Slides
9Multi-page documents: the newsletter
A newsletter repeats a structure on every page: masthead, columns, styles, page numbers.
  • Use paragraph styles so every heading matches
  • Set up columns and a masthead
  • Keep a multi-page document consistent
Slides
10Folded work and print preparation: bleed, trim and safe area
Printers cut paper, and the cut is never perfect. Bleed, trim and the safe area protect your design.
  • Explain bleed, trim and safe area
  • Set up a document with 3 mm bleed
  • Plan the panel order of a tri-fold brochure

11Exporting a print-ready PDF and briefing a printer
A design is only finished when a printer can print it right: a PDF with fonts, images and bleed — and a clear brief.
  • Export a print-ready PDF with bleed
  • Run a final pre-flight check
  • Write a print brief for a print shop

Design, produce and present a four-page magazine for your centre — everything from the term in one publication.
