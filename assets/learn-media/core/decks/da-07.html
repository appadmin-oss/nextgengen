Data Appreciation · Week 7 · Idea 1

Understand it

A table is tidy when it has one row per thing, one column per question, one value per cell, and a header row. Then the spreadsheet can answer questions for you.

  • Sort: select the WHOLE table, then Data → Sort range, with "has header row" ticked. Never sort a single column — it scrambles every row.
  • Filter: Data → Create a filter, then pick values in a column. Other rows are hidden, not deleted — turn the filter off and they come back.
  • Find (Ctrl+F) locates a word; Find and Replace (Ctrl+H) fixes it everywhere at once. Check the count before you press Replace all.

Data Appreciation · Week 7 · Key words

Key words

Sort
put rows in order by a column
Filter
show only some rows, without deleting the rest
Tidy data
one row per thing, one column per question
