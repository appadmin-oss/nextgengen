Data Appreciation · Week 11 · Idea 1

Understand it

Pick the file type for the job. Still being edited? Send the editable file (.docx, .xlsx). Finished and must look the same everywhere? PDF. Data for another app? CSV. Photos JPG; screenshots and logos PNG.

Attachment or link? An attachment is a copy — edits do not travel back. A shared link points to ONE file everybody works on.

Access: give the least that does the job.

  • Viewer reads · Commenter suggests · Editor changes.
  • Restricted (only people you add) is the safe default; "anyone with the link" travels further than you think — never for personal data.
Data Appreciation · Week 11 · Idea 2

Understand it

Working together: use comments instead of typing into someone's work, and version history (File → Version history) to see who changed what and to restore an older version.
