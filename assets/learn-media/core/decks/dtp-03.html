Type I: choosing and using fonts

Most of a page is words. The right font, size and spacing make them easy to read.

Desktop Publishing · Week 3 · Idea 1

Understand it

  • Serif fonts have small strokes at the ends of letters (Georgia, Times); sans-serif fonts do not (Arial, Inter). Both are readable; pick one for body text and keep it.
  • Size: body text for print is usually 10–12 pt; for screens 16 px. Headings are bigger.
  • Line length: 45–75 characters per line is comfortable. Longer lines tire the eye.
  • Line spacing: about 1.2–1.5 times the font size.
  • Two fonts at most: one for headings, one for body. Never decorative fonts for body text.
Desktop Publishing · Week 3 · Idea 2

Understand it

CAPITALS are hard to read in long stretches, and underline looks like a link. Use bold for emphasis.

Desktop Publishing · Week 3 · Practice

Now you do it

  1. Compare three fonts on the same paragraph
  2. Find the size where your partner reads it easily at arm's length
  3. Set line spacing and line length

Need a hand? Start with one sans-serif font only; change just size and weight.

Done early? Pair a serif heading font with a sans-serif body font and explain why they work together.
