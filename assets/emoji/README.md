# Reaction emoji

The six Community reactions (👏 ❤️ 🔥 💡 🎉 🙌), animated, from Google's
Noto Animated Emoji (https://googlefonts.github.io/noto-emoji-animation/),
licensed CC BY 4.0. Downscaled to 96 × 96 so a feed of them stays light on a
phone's data. File names are the emoji's code points in hex, joined with `_`.

Only these six are self-hosted. Any other emoji in a post renders as text.
