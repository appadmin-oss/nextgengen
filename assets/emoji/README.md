# Reaction emoji

The six Community reactions (👏 ❤️ 🔥 💡 🎉 🙌), animated, from Google's
Noto Animated Emoji (https://googlefonts.github.io/noto-emoji-animation/),
licensed CC BY 4.0. Re-encoded at 72 × 72, 15 fps, 96 colours (about 160 KB
for all six, from 1.9 MB at source) so a feed of them stays light on a phone's
data. They render at 20 px in a reaction pill and 68 px in the burst. File names are the emoji's code points in hex, joined with `_`.

Only these six are self-hosted. Any other emoji in a post renders as text.
